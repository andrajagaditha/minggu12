Halo! Nama saya Diyandra Jagadditha, mahasiswa aktif program studi Sistem Informasi di Fakultas Ilmu Komputer. Saya memiliki ketertarikan di bidang data serta analisis sistem informasi. Saya senang mempelajari teknologi baru yang dapat membantu menyelesaikan permasalahan.
