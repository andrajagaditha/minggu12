A. Profil Saya

Halaman web ini dibuat menggunakan HTML5 murni tanpa CSS untuk memenuhi instruksi pembuatan struktur dasar web. Pembuatan halaman ini menjadi latihan untuk memahami dasar-dasar pengembangan web, dengan harapan saya dapat menggunakan HTML untuk membuat halaman web yang lebih kompleks.
