A. Profil Saya

Halo! Nama saya Diyandra Jagadditha, mahasiswa aktif program studi Sistem Informasi di Fakultas Ilmu Komputer. Saya memiliki ketertarikan di bidang data serta analisis sistem informasi. Saya senang mempelajari teknologi baru yang dapat membantu menyelesaikan permasalahan.

Halaman web ini dibuat menggunakan HTML5 murni tanpa CSS untuk memenuhi instruksi pembuatan struktur dasar web. Dalam pembuatan halaman ini, saya menggunakan berbagai tag HTML untuk menyusun struktur dan menampilkan informasi, serta mempelajari fungsi setiap tag agar dapat digunakan sesuai kebutuhan. Pembuatan halaman ini menjadi latihan untuk memahami dasar-dasar pengembangan web, dengan harapan saya dapat menggunakan HTML untuk membuat halaman web yang lebih kompleks.
