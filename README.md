# Portofolio Diyandra Jagadditha

Tugas Pemrograman Web 1 - Program Studi Sistem Informasi, Universitas Dian Nuswantoro.

## Deskripsi
Halaman portofolio pribadi yang dibuat dengan HTML5 murni tanpa CSS.

## Isi Halaman
- Profil
- Riwayat pendidikan (tabel)
- Keahlian dan hobi (list)
- Proyek dan aktivitas akademik
- Form kontak pengunjung

## Elemen HTML yang Digunakan
`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `table`, `ul`, `ol`, `form`

## Cara Menjalankan
Buka file `index.html` di browser.
